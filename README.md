# いすみ市議会ウォッチ（shigikai-watch）

いすみ議会だより 第1〜84号（2006〜2026年）をもとに、千葉県いすみ市議会の顔ぶれと議員の一般質問を見える化する静的サイトです。

- `index.html` / `style.css` / `app.js` … ページ本体（ビルド不要）
- `data.js` … 議員別・任期別の一般質問回数（第51号・第80号は未入手のため未集計）

## 公開
Vercel で Import するだけで公開できます（Framework Preset: Other、Build Command なし）。

## 注意
- 2026年の年齢は第5号（2006年）掲載の年齢＋20の推定値です。
- 特定の政党・候補者を支持・推薦するものではありません。
